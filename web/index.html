evm-scan

Permissionless asset indexing over your own node. Contracts are found by watching the head, or registered on-chain as hints. Only promoted ones get a full history walk — down to whatever history the node kept, never assuming genesis. The result is a per-account discovery index, committed back on-chain as a merkle root. See it drawn as a graph of accounts and the contracts they share.

Names resolve through ENS's on.eth chain registry, on Ethereum mainnet — one eth_call, on-chain, no gateway. It answers with the chain id, so you do not have to remember it. It deliberately publishes no RPC endpoints: an endpoint URL is where an API key lives, so that part stays yours to supply.
Most chains are not in the registry — it is new, and testnets are not its early population. Typing the id is an ordinary way in, not a failure; everything downstream is identical, including the check below.
Sent to the daemon and stored so a restart can bring the chain back. It is never returned in an API response — the URL usually carries a provider's key. Before anything is written, the daemon dials it and asks the node for its own chain id: if that disagrees with the number above, the network is refused. That check is what makes a typo loud instead of silent.
A chain reached over somebody else's RPC starts unverified: it is indexed and served, but nothing it produces can back an on-chain commitment until you say so deliberately.
Head discovery starts off. The sweep asks for logs with no address filter, which is the first thing a shared endpoint refuses; turn it on once you know what your provider allows. Registered and promoted assets are followed either way.
This deployment does not allow adding networks at runtime.

Look up an account

Balances are read live from the node with eth_call at head — never derived from indexed events. The reader for that is deployless — the call carries its own bytecode — so it runs the same anywhere: and this page will read your balances in your browser, from your node, without this deployment touching them. Prices come from the chain too: Chainlink feeds and Uniswap pools found through a second deployless call, never a quote API.
Names (.eth, .gwei, .wei) are the one exception to reading only your own node: they resolve against a public mainnet RPC in your browser, because the registries live on mainnet whichever chain this deployment indexes. Only the name is sent, and only when you type one.
