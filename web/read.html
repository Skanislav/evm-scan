What did this name commit to?

An account the index has committed to a root is read back here through ENS alone: every account has a name under the registry's resolver, its contracts come from that name's text records, verified on chain before they are returned, and the balances from one call to a node you choose. This page never sends the daemon an account.

<address as hex>.hints.<parent> · reading its contracts record means following the resolver's gateway from this browser. On the registry's own chain the callback checks the answer against the latest finalized root; on another chain (ENS on mainnet, registry on Base) a HintSignedResolver only checks that the publisher's pinned key signed it. The steps say which one answered, and what was and was not checked.

what left this browser
    The record is what HintResolver.sol serves: lowercase addresses joined by commas under evmscan.contracts, the chain id under evmscan.chain, the epoch and root beside them. Any ENS client reads it; this page only adds the balances. The lens is AssetLens.sol, run as a deployless eth_call with its creation code as the payload, so there is no contract address to trust and no upgrade key.
